# workplace_safety_object_detection_Mini_project
Workplace safety monitoring using YOLOv8n fine-tuned on the SH17 dataset to detect safety helmets and reflective vests, with an OpenCV webcam demo.
Mini project for M.Tech Computer Science and Engineering (Data Science), COEP Technological University, Pune. The system detects visible safety helmets and safety vests. It does not verify worker PPE compliance, which needs additional person-to-PPE association logic.
